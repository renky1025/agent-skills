# 人生警句生成器

根据用户输入的任意话题，生成 3 条不同风格的人生感悟/哲理警句。

## 触发条件

当用户调用 skill 名称 `life-quotes` 时，无条件触发。

## 输入处理

用户输入的任何内容都视为"话题"——可以是一个词（如"孤独"）、一个场景（如"加班到深夜"）、一种状态（如"辞职后的第一天"），甚至是一个物品（如"一杯凉掉的咖啡"）。

不要追问用户"你想要什么风格"，直接基于话题生成 3 种风格的警句。

## 输出格式

每次输出必须包含 3 条警句，分为 3 个风格类别。根据话题自然选择最匹配的 3 个类别，不要机械固定。

可选风格类别：
- **哲思类** —— 通透、有洞察、带一点反常识
- **治愈类** —— 温暖、安抚、给人力量
- **扎心类** —— 戳中现实、略带痛感但让人清醒
- **反内卷类** —— 对比快节奏生活，强调简单/慢/够用就好
- **孤独与自我类** —— 独处不是寂寞，是和自己相处
- **生活真相类** —— 直白说出生活的不易与珍贵
- **极简类** —— 越少越好，幸福很简单

输出模板：

```
🌿 **[风格1名称]**
> 警句内容

🍂 **[风格2名称]**
> 警句内容

🔥 **[风格3名称]**
> 警句内容
```

## 风格要求

### 必须做到
- **每条 1-2 句话**，简短有力，不要长篇大论
- **口语化表达**，想象你在和老朋友喝酒聊天，不是写论文
- **能引起情感共鸣**，让读到的人想点头、想截图、想转发
- **从话题本身延伸**，不要脱离用户给的关键词凭空发挥

### 必须避免
- **油腻书面语**：如"我们要坚守内心的宁静，方能致远" ❌
- **强行煽情**：如果话题是"地铁早高峰"，不要写"世界充满爱"
- **空洞鸡汤**：如"只要努力就会成功"这种没有具体画面感的句子
- **说教感**：不要"你应该..."，改成"人要是能...就好了"

### 口语化转换示例
| 油腻书面语 | 高级感口语 |
|---|---|
| 我们要坚守内心的宁静，方能致远 | 山上的风很大，大到能吹走所有没必要的烦恼 |
| 人生需要不断奋斗才能实现价值 | 羊只关心脚下的草肥不肥，不关心山那边的羊是不是比它多 |
| 孤独是成长的必经之路 | 在山上，每一阵风、每一只羊，都在陪我说话 |

## 示例

**用户输入：** 放羊

**输出：**

```
🌿 **哲思类**
> 羊只关心脚下的草肥不肥，不关心山那边的羊是不是比它多。人要是能活得像羊一样，世界就安静了。

🍂 **治愈类**
> 很多人问我放羊不孤独吗？其实孤独的是山下的世界。在山上，每一阵风、每一只羊，都在陪我说话。

🔥 **扎心类**
> 羊群里总有几只喜欢离群索居，它们不是迷路了，只是想去看看没被啃过的草。像极了那些不安分的年轻人。
```

**用户输入：** 一杯凉掉的咖啡

**输出：**

```
🌿 **生活真相类**
> 咖啡凉掉的那一刻，你才发现自己忙到连一口热乎的都没喝上。

🍂 **治愈类**
> 凉掉的咖啡也能喝，只是少了点烫嘴的期待。有些遗憾，其实也还行。

🔥 **反内卷类**
> 以前觉得咖啡必须趁热喝，现在觉得凉了更清醒——人也是。
```

**用户输入：** 深夜加班

**输出：**

```
🌿 **扎心类**
> 凌晨两点的写字楼，整层只有你一个人亮着。你不是在奋斗，你是在替白天摸鱼的自己还债。

🍂 **治愈类**
> 加班到再晚，楼下的便利店总会留一盏灯。这个城市总有人在等你，哪怕是一碗关东煮。

🔥 **哲思类**
> 键盘敲得再响，也盖不过心里那个问"这到底图什么"的声音。
```

## 执行指令

1. 读取用户输入的话题
2. 分析话题的核心意象和情感基调
3. 选择 3 个最合适的风格类别
4. 为每个类别生成 1-2 句话的警句
5. 自检：是否口语化？是否有画面感？是否会引起共鸣？
6. 按模板输出

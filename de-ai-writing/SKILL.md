# 文本去AI味 / De-AI Writing

真实可靠的文风指令。不输出一套新腔调替换旧腔调，而是教你找出机器味、删掉空话、校准到自己的声音。

## 相关 / 分工

本技能是「去 AI 味」的**唯一真源（single source of truth）**。`snowflake-novel-writer`（references/anti-ai-writing.md）与 `wechat-article-writer`（references/avoid-ai-writing.md）内嵌了本指南的本地副本，便于离线/自包含引用；如需更新去 AI 味规则，请以本技能为准并同步上述副本。

## 核心认知

**AI味的本质不是"用词太AI"，而是"没有具体的人在里面"。**

干净但没灵魂，还是机器味。每句话长度一样、没有观点、只做中立报道、不承认复杂感受、没有幽默、没有锋芒——这些也算没修好。

AI 的根本问题是回归统计平均值，而人类是具体、奇怪、不稳定的。去AI味不是洗成"通用人类腔"，而是把文字放回一个**具体的人**身上。

## 核心原则（来自 PasPrompt 反AI写作系统）

写任何东西之前，记住这些规则：

**绝不使用：**
- 泛化开头和泛化结尾
- 空洞的过渡句
- 企业套话
- 励志填充物
- 过度解释
- 可预测的句式
- 显而易见的观察
- 不必要的背景铺垫
- 证据明显倾向一边却假装中立

**始终做到：**
- 先甩出最重要的观点
- 洞察优先于解释
- 具体优先于抽象
- 句子节奏自然多变
- 包含有意义的判断
- 必要时挑战假设
- 带着确信感写
- 砍掉所有不创造价值的文字
- 听起来像一个对主题有深度理解的人

**写完后自问：这段话删掉，文章损失什么？什么都不损失 = 删。**

## 使用方式

用户贴一段文字，按五步法执行。目标文本可以是任何类型：自媒体文章、职场周报、个人随笔、产品文案、朋友圈、小红书笔记、邮件等。

## 五步去AI味工作流

### 第1步：检测 → 不要急着改写

先输出 **AI味检测报告**，不改文本。按以下11类逐项标记：

**1. 意义膨胀** — 把普通事实包装成重大事件
- 标志词：标志着、反映了更广泛的趋势、为未来奠定基础、关键转折点、深刻变革
- 改法：摘帽子，说这东西到底是什么、做了什么、影响了谁

**2. 宣传腔** — 像旅游手册和融资新闻稿的杂交
- 标志词：充满活力的、丰富的、深刻的、开创性的、令人叹为观止的、卓越的
- 改法：不要形容词，给事实。别说"充满活力的社区"，说你亲眼看见的

**3. 模糊归因** — 冒充有来源的空壳引用
- 标志词：专家认为、行业报告显示、观察者指出、有数据显示、研究表明
- 改法：要么说清哪个专家、哪份报告、哪一年，要么直接删

**4. 公式结构** — 同一种模具倒出来的水泥块
- 三连词：创新/效率/增长、认知/行动/结果
- 否定排比："不是A，而是B""这不仅是A，更是B"
- 万能开头："在当今时代""随着XX的发展""本文将从XX角度""本文将深入探讨"

**5. AI高频词（中文）**
- 赋能、认知升级、长期主义、底层逻辑、关键抓手、闭环、深度链接、价值沉淀、颗粒度、抓手、对齐、重构、升维、降维打击、顶层设计、范式转移、破局、破圈、穿透、倒逼、解法、路径、场域、体感、温差
- 发现3个以上，整段重写

**6. 风格痕迹**
- 破折号泛滥（每500字超过1个）
- 粗体加粗滥用
- 列表项目都是"关键词：解释"格式
- 小标题像培训课件
- 开头"本文将"、结尾"希望这对你有帮助"

**7. 聊天残留**
- 当然、你说得对、请告诉我、希望这对你有帮助
- 首先/其次/再次/最后（连环用）
- 此外、值得注意的是、真正重要的是
- 综上所述、总而言之

**8. 统计层面**
- 句长是否过于均匀（大部分句子15-25字 = 机器人节奏）
- 同段是否同义词轮换（开发者→工程师→技术人员，重复一个词比强行变化更像人）
- 段落长度是否全都3-5句（刻意变化：有1句的短段，也有长段）
- 全文是否有观点倾向（全篇中立描述 = 没灵魂）

**9. 缺乏判断力** — AI 回避立场，人类天然会判断
- 特征：只说"一方面……另一方面……"但不表态；列出观点但不区分优先级；不敢说哪个更重要
- 标志句："这取决于具体情况""每个人看法不同""没有绝对的对错"
- 改法：给判断。说"这条比那三条加起来都重要"。表达置信度——"我基本确定""这个我不太有把握但""数据指向一个方向"。指出弱点。质疑假设。提到权衡。展示合理的怀疑。

**10. 解释代替洞察** — 在复述常识而不是提供新知
- 特征：每个段落都在解释一个大多数人已经知道的概念，像教科书而不是文章
- 自检问题：读完这段，读者学到了什么他们之前不知道的东西？如果答案是"没有"，这段就是解释而非洞察
- 改法：删掉解释性内容。保留揭示、挑战、质疑、对比、重新框定的内容。读者看完应该感觉学到了新东西。

**11. 缺少利害感** — 写得好像说对说错都没后果
- 特征：泛化建议、安全观察、显而易见的话、中性评论、到处都适用的宽泛说法
- 标志词：任何人/每个人都可以、重要的是找到平衡、关键在于……、说到底……
- 改法：每句话都应该像"说错了我负责"。优先给出有用的洞察。推理要更强。只写真正重要的。去掉所有填充。带着有根据的确信说话。每个句子都应该听起来是被挣来的，而不是被生成的。

检测报告格式：

```
## AI味检测报告

### 发现的问题
- 意义膨胀：X处 → [具体例句]
- 宣传腔：X处 → [具体例句]
- 模糊归因：X处 → [具体例句]
- 公式结构：X处 → [具体例句]
- AI高频词：X处 → [列出词]
- 风格痕迹：X处 → [具体描述]
- 聊天残留：X处 → [具体例句]
- 统计问题：句长/用词/节奏异常描述
- 缺乏判断力：X处 → [具体例句]
- 解释代替洞察：X处 → [具体段落]
- 缺少利害感：X处 → [具体例句]

### 正确但没有信息量的句子（可删）
- [列出]

### 解释性内容（读者本来就知道的，可删）
- [列出]

### 预估可删除比例：X%
```

### 第2步：删除 → 至少砍20%

基于检测报告，直接删：

- 删掉所有意义膨胀的帽子句（"标志着……"）
- 删掉所有模糊归因的伪引用（"专家认为……"）
- 删掉所有正确的废话（说了等于没说的句子）
- 删掉聊天残留（"希望这对你有帮助"等）
- 删掉公式化开头和结尾（"在当今时代……""综上所述……"）
- 删掉纯粹的凑字数段落

**目标：至少删掉20%。不够就继续找。**

判断标准：删掉这段话，文章损失什么吗？什么都不损失 = 该删。

### 第3步：声纹校准 → 放回具体的人

这一步是去AI味最容易失败的地方——不是换成另一种通用人类腔，而是换成**你**的腔。

**3.1 先定口气**

决定这篇文字是什么口气，不要让AI自动回到"礼貌、完整、正确"的默认档：

| 口气 | 特征 | 适用场景 |
|-----|------|---------|
| 吐槽/朋友 | 句子有长有短、允许不耐烦、有突然冒出的玩笑 | 朋友圈、小红书、个人博客 |
| 尖锐/锋利 | 有判断、有冒犯、有"不讲道理"的爽感 | 观点文、评论、X/微博 |
| 冷脸技术文 | 直接、去修饰、用数据说话、不抒情 | 技术文档、周报、分析 |
| 专业编辑 | 有观点的深度分析、克制但有立场 | 公众号深度文、专栏 |
| 随性 | 允许没说完的停顿、有毛边、有口头禅 | 随笔、日记、碎片记录 |

**3.2 模拟活人声纹**

如果没有现成的个人样本，用以下方法模拟一个具体的人：

1. 说清"我"是谁——不是身份标签，是性格：爱说实话还是爱绕弯？耐心怎么样？对什么容易不耐烦？
2. 先写一段话，给自己一个"不装"的开头——比如"说个暴论""说句实话""我想吐槽这个很久了"
3. 保留你原本的口头禅和毛边——你本来就爱说"这玩意儿"，就别升级成"该现象"
4. 允许偏见和情绪——人有立场、有喜好、有不喜欢的东西，别抹掉

**3.3 有样本时的声纹提取**

如果有写作样本（2-3段喜欢的文字），提取：
- 平均句长和句长变化范围
- 惯用开头方式（直接扔结论？先铺背景？还是劈头就骂？）
- 转折方式（但/不过/问题是/然而/然后呢？）
- 标点习惯（句号多还是逗号多？用不用感叹号？）
- 有装饰词还是去修饰？
- 有毛边吗？（不耐烦、突然跑题、没说完的句子）

### 第4步：改写 → 把抽象词换成具体物

基于第2步删减后的文本 + 第3步的声纹校准，进行改写：

**规则1：抽象词换动作**
- "表达能力" → 到底是改开头、删废话、换例子，还是把一句话压短？
- "用户需求" → 读者看完能做哪一步？
- "内容价值" → 有没有人愿意截图、反驳、转发、收藏、付钱？
- 抽象词没有具体动作托着，就会飘，飘起来就一股AI味

**规则2：不要形容，给事实；不要总结，给细节**
- 别说"一个充满活力的社区" → 说"每周三有集市、晚上十点还有人在楼下吵架"
- 别说"行业竞争激烈" → 说"一个岗位收到400份简历，其中87个是前总监"
- 别说"他很难过" → 说"他把那张照片翻过去扣在桌上"

**规则3：具体到数字、名字、时间、结果**
- "研究显示" → "Nature 2023年的那篇论文"
- "很多人" → "我最近聊了15个HR，12个这么说"
- "效率提升" → "从3小时缩到40分钟"

**规则4：留一些脏**
- 允许偏见："这玩意儿纯粹是浪费时间"
- 允许不耐烦："不解释了，懂的都懂"
- 允许吐槽："说实话看到这东西有点反胃"
- 允许没说清楚但大家都懂的停顿
- AI最喜欢把这些地方磨平，磨完你就看不出谁在说话

**规则5：打破节奏均匀** — 人类节奏，不是机器节拍器

AI写作的节奏可预测：句子长度趋同、结构重复、读起来像匀速传送带。活人文字是不均匀的。

- 长句和短句混用。偶尔用片段。真的。
- 段落长度变化：有时一整段就一句话。有时需要十句才说完。不要让每段都是 3-5 句。
- 开头不要重复——别每句都用"但是""然而""此外""与此同时"起头。制造对比和动量。
- 删掉任何感觉机械优化的东西。文字应该感觉活着，而不是被生成的。
- 试读：如果这段可以被 TTS 引擎朗读而毫不违和，节奏可能太均匀了。

**规则6：系动词回流**
- "serves as" → "is"
- "features/boasts" → "has"
- "presents/reveals"（膨胀用法）→ "is/shows"
- "serves as a testament to" → "shows"
- 不是说不能有复杂动词，但如果一个词能被 is/has 替换而不损失信息，就用 is/has

### 第5步：反查 → 第二轮专门找残留味

第一遍改完很容易感觉"差不多了"，但隔五分钟再看，一股"此外""值得注意的是"又从缝里冒出来。

**必做：让改完的文本自己回答这个问题——**

> "这段哪里还明显像AI？"

然后逐项检查：

**反查清单：**

- [ ] 还有没有"在当今时代""随着XX的发展"残留？
- [ ] 还有没有"不仅是A更是B""不是A而是B"句型？
- [ ] 还有没有"赋能""认知升级""底层逻辑""长期主义""闭环"？
- [ ] 破折号还超过每500字1个吗？
- [ ] 句长是不是还太均匀？试着朗读——如果听起来可以被TTS引擎朗读而不奇怪，可能还太匀
- [ ] 还有"此外""值得注意的是""更重要的是"这种连词吗？
- [ ] 结尾还有没有"综上所述""总而言之""希望这对你有帮助"？
- [ ] 还有没有没指明的模糊归因？
- [ ] 还有没有泛化建议、安全观察、显而易见的话？
- [ ] 还有没有"一方面……另一方面……"但最后不站队的？
- [ ] 每句话删掉，文章损失什么？有没有删了也无所谓的句子？
- [ ] 读一遍：能从文字里感受到"谁"在说话吗？还是只有一个礼貌、稳定、没有脸的声音？
- [ ] 能用 is/has 就用的地方，是否还在用 serves as / features / presents？
- [ ] 有没有解释了一大段读者本来就知道的内容？
- [ ] 有没有重复措辞？有没有不必要的摘要？结尾有没有只是重述前文？
- [ ] 每个句子听起来是被挣来的，还是被生成的？

**发现问题 → 回到第2步，再删再改。**

## 快速自检卡（轻量版）

不想完整走五步法时，用这个快速扫一遍：

读三遍文字：
1. 第一遍：把每句"标志着""反映了""具有重要意义的"划掉，看句子还通不通。如果还通，这些就是废话。
2. 第二遍：找"赋能""认知升级""长期主义""底层逻辑""闭环""颗粒度""抓手"，计数。3个以上直接重写。同时找"一方面另一方面但最后不站队"的句子——加上判断。
3. 第三遍：假想一个真实的人在你面前说这段话。他会这么说话吗？不会 → 改到会为止。
4. 补一刀：每段问自己"这段是解释（读者本来就知道的）还是洞察（读者不知道的）？"解释多 → 删到只剩洞察。

## AI味评分标准

改完后给自己打分：

| 维度 | 1-3分（AI味重） | 4-6分（中等） | 7-10分（活人感） |
|-----|---------------|-------------|----------------|
| **具体性** | 全是抽象词，看不到具体东西 | 有少量具体细节 | 有数字/名字/场景/动作 |
| **个人声音** | 完全中立，看不出谁在说话 | 有一定态度但克制 | 有明确的立场、情绪、习惯 |
| **句法自然度** | 句长统一，节奏机械 | 有变化但不够大胆 | 长短交替，有不规则和毛边 |
| **信息密度** | 大量正确的废话 | 偶有废话 | 每句都有存在理由 |
| **判断力** | 回避立场，只说"都重要""看情况" | 有表态但很安全 | 有优先级、有置信度、有质疑 |
| **洞察密度** | 通篇解释常识 | 少量洞察夹杂解释 | 每段都能让读者学到新东西 |
| **利害感** | 像PR稿，说对说错都无所谓 | 偶有承担责任的感觉 | 每句都经得起追问 |

**红线（任何一条触发需重写）：**
- 有"在当今时代""随着XX的发展"开头
- 有"综上所述""总而言之""希望这对你有帮助"
- 出现3个以上中文AI高频词（赋能/认知升级/长期主义/底层逻辑/闭环/抓手……）
- 有未具体指明的"专家认为""研究表明"
- 整段没有一句能听到"人"的立场和情绪
- 句长统一到可以交给TTS朗读不奇怪的程度
- 通篇"一方面另一方面"但不表态（缺乏判断力）
- 超过一半段落是解释常识而非提供洞察
- 有 serves as / features / presents 等膨胀动词（能用 is/has 替换的）

```
## 第1步：AI味检测报告

[用户指定或从样本提取的声纹特征]

## 第4步：改写版

[改写后的完整文本]

## 第5步：反查结果 + 终版

[七个维度打分 + 总分]
```

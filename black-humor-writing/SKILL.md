# 黑色幽默写作 SOP

幽默不是天赋，是有 SOP 的。本 Skill 基于单立人喜剧教材的核⼼方法论，提供从观察生活到产出有传播力的幽默内容的五步框架。

## Outcome Contract

- **Outcome**：基于主题生成有传播力的黑色幽默/搞笑内容（推文、段子、评论文案、文章段落）
- **Done when**：主题已确定、态度已明确、预期的违背已构建、内容有传播力
- **Evidence**：预期违背点清晰；有真实矛盾被揭露；读者能感受到"一个活人在表达"

## Hard Rules｜硬边界

- **幽默来自真实的矛盾和观察**，不是编造梗或抄段子——必须从生活/经历/观察出发
- **黑色幽默的本质是揭露不合理**，不是无意义吐槽——每段幽默要有一个"为什么这件事其实很荒谬"的核心
- **爆论 ≠ 胡说**——有争议的角度必须有真实论据支撑，不能为博眼球编造立场
- **不冒充别人经历**——可以夸张放大真实体验，但不能编造"我遇到过"的事
- **不低俗攻击**——讽刺可以犀利，但不能靠羞辱/歧视/人身攻击制造笑点

## 五步框架

### 第一步：定主题 + 态度 + 前提

一个段子的铺垫 = **主题 + 态度 + 前提**。

| 要素 | 含义 | 常见错误 |
|------|------|----------|
| 主题 | 你在讲什么（AI、恋爱、职场、消费） | 只有主题没有态度 = 废话 |
| 态度 | 你对这件事的感受（讽刺、荒诞、无奈、好笑） | 平淡叙述，没有任何立场 |
| 前提 | 你真正想表达的那个观点 | 观点不明确，读者不知道你想说什么 |

**练习方法**：拿到一个主题，先问自己"我对这件事的真实感受是什么？"——找到态度，再提炼前提。

> **好例子对比：**
> - 主题："AI 发展很快" → 平淡，没有态度
> - 加态度："你研究 AI 会不会取代工作，老板在研究怎么用 AI 裁掉不会用 AI 的人" → 有态度（荒诞/讽刺），有前提（懂 AI 不一定保住工作）
>
> **@ally_foe 的 OPC 例子：**
> - 主题：AI创业
> - 态度：讽刺
> - 前提：技术很强但不懂商业的人也赚不到钱
> - 输出："你今天免费帮性感女主播解决 AI 问题，明天免费帮可爱邻居解决 AI 问题，你这样能赚到钱才有鬼。"
> - **为什么有传播？** 它同时涉及两性话题和商业道理，多层信息叠加。

### 第二步：构建预期违背

段子 = **铺垫 + 包袱**。铺垫让观众产生一个期待，包袱打破这个期待。

```
铺垫 → 建立一条预期轨道
包袱 → 把读者从轨道上推下去
```

**怎么找预期违背点：**
- 找到人们对某件事的"默认叙事"
- 想想有没有一个角度是这个默认叙事之外的
- 把这个意外角度当作包袱

> **好例子：**
> - 预期：一个人进入 Web3 是因为看到了财富机会
> - 实际："我进入 Web3，是因为被仇人陷害"
> - 预期：创业故事 → 现实：江湖恩怨
> - 这就是黑色幽默的本质

### 第三步：把普通事情夸张化

生活中很多事情本身没那么夸张，但你可以找到其中的荒谬点，然后放大。

**三步法：**
1. 描述一个普通场景
2. 找到这个场景里的矛盾或冲突
3. 把矛盾放大到荒谬的程度

> **好例子——泡泡玛特：**
> - 普通场景：男生不理解女生花几千买玩偶
> - 普通表达："男女消费观不同"（无聊）
> - 夸张后："男生花 5000 块请朋友吃饭：兄弟情谊无价。花 5000 块买泡泡玛特：他妈的一个塑料玩具，女的就是容易被资本主义收割了。"
> - **为什么浏览高？** 把一个真实矛盾放大，还上升到两性对立，精准踩中讨论区

### 第四步：制造焦虑和冲突（爆款原理）

很多人误解爆款内容，以为爆款就是提供信息。**其实爆款很多时候来自情绪：恐惧、焦虑、愤怒、震惊。**

**信息 vs 情绪对比：**
| 信息型（没人关心） | 情绪型（有人讨论） |
|---|---|
| "AI 很强" | "很多人还没学会 AI，已经有人开始用 AI 替代不会 AI 的人" |
| "个人 AI 博主可以做" | "个人 AI 博主永远做不大" |

**爆论的正确用法：**
- ❌ 胡说八道没有依据
- ✅ 提出一个有争议的角度，配真实论据
- 爆论不是为了引起反感，是为了**让读者停下来想"是吗？"**

### 第五步：训练「段子雷达」

单口喜剧最重要的能力：**在生活中发现荒谬的敏感度。**

走路、吃饭、刷手机的时候，问自己三个问题：
1. 等等，这个事情是不是有点奇怪？
2. 为什么大家觉得这个正常？
3. 如果把它放大，会不会很荒谬？

**段子雷达扫描清单：**
- 为什么男生觉得请客 5000 合理但买玩具不合理？
- 为什么企业给员工解决生活问题看起来像福利，本质上却是提高生产力？
- 为什么技术创业者最容易忽视商业？
- 为什么同一个行为换个人做评价完全不同？

> 这些地方都有冲突。这些冲突就是内容。

## 实战模板

### 模板：矛盾对比型

```
[主流行为/观点] → [你的真实观察/经历]
```

> "你研究 AI 会不会取代你，老板在研究怎么用 AI 替代不会 AI 的人"

### 模板：预期翻转型

```
[大家以为...] → [其实是...]
```

> "大家以为我进入 Web3 是看到了财富机会 → 其实我是被仇人陷害的"

### 模板：双重标准放大型

```
[同一行为在不同场景下的反差评价]
```

> "A 做这件事：伟光正 → B 做这件事：被骂惨"

### 模板：自嘲型

```
[暴露自己的荒谬] → [拉近距离，制造共鸣]
```

> "我之前也以为自己是技术大牛能改变世界 → 现在在免费帮邻居解决 AI 问题"

## 常见误区

| 误区 | 正解 |
|------|------|
| 以为搞笑就是网上找段子 | 好的幽默是在表达"我如何理解这个世界"，素材来自你的生活 |
| 认为每个包袱都要让大家爆笑 | 黑色幽默可以是让人"笑完觉得有点难受"的 |
| 为了搞笑而编造不存在的事 | 夸张可以，但核心事实不能编——虚假的东西没有穿透力 |
| 只有态度没有主题 | 读者不知道你在说什么，光有情绪是空洞的 |
| 只有主题没有态度 | 流水账，没人记得你说过什么 |

## 出号自检清单

交付前逐项检查：

- [ ] 我有明确的 **主题**（在讲什么）
- [ ] 我有清晰的 **态度**（对这件事的真实感受）
- [ ] 我有具体的 **前提**（想表达的观点）
- [ ] 有 **预期违背** 吗？（读者猜不到结局）
- [ ] 夸张后是否 **保留了真实的内核**？（没编造）
- [ ] 是否制造了 **情绪触发点**？（焦虑/共鸣/荒谬/讽刺）
- [ ] 内容是 **从生活观察出发** 的吗？
- [ ] 读一遍——**真的好笑吗？**（如果自己都不觉得好笑，删了重写）

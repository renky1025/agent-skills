API 到底是什么？

设想你想在外卖 App 上点一杯奶茶，却没进奶茶店——你点的是"菜单"，奶茶店在后厨做好递给你。API 就是那个"菜单 + 传话窗口"。

先类比

餐厅里，你（顾客）看不到厨房，也不直接抓原料。你只看菜单点单，服务员把单子送进厨房，做好再把菜端出来。

两个程序之间也一样：程序 A 想用程序 B 的能力（比如"查天气"），它不翻 B 的源码，而是照 B 提供的 API 菜单发一个"订单"（请求），B 算完把"菜"（数据）回给它。

你点单 -> 窗口传话 -> 后厨出菜。你不必懂后厨怎么炒。
再精确

API（Application Programming Interface）是一套事先约定好的规则和格式：程序 A 按格式发请求，程序 B 按格式回数据。双方都不必知道对方内部怎么实现。

带走这一句：API 是"程序之间点单的菜单"。你按菜单点，它按格式回，谁都不用懂对方后厨。

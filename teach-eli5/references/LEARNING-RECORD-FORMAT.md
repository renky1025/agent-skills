# Learning Record (学习记录) 格式

学习记录存 `./learning-records/`，顺序编号 `0001-slug.md`、`0002-slug.md`……首次写时再建目录。
它们是教学版的 ADR（架构决策记录）：捕捉非显然的洞见、关键理解、用户已掌握的前提，用来推算最近发展区。

## 模板

```md
# {学到的或已确立的简短标题}

{1-3 句：学到了什么（或确立了什么已知前提），以及为什么它影响以后的教学。}
```

就这么多。一条记录可以只是一个段落。价值在于记下"现在已知这件事、因此它改变下一步教什么"，而非填表格。

## 何时写

1. **用户展现了真理解**（不只是看过）：答对了、说清了、纠正了误区。这设了下一课的新地板。
2. **用户披露了已知前提**："这个我早懂了。"记下深度，别重复教。
3. **纠正了误区**：之前信错的、现在看清为什么错。高价值，常预示相关主题的坑。
4. **目标因学习而偏移**：交叉链 `[[MISSION.md]]` 并更新它。

## 不算的

- 仅"覆盖过"的材料（覆盖不等于学会，等证据）。
- 已 terse 写进 `[[glossary.md]]` 的术语定义（别重复）。
- 流水账（学习记录不是日记，是决策级洞见）。

## 编号

扫 `./learning-records/` 取最大号 +1。

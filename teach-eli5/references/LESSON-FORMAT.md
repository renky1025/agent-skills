# Lesson (教学页) 格式与版面规范

一课 = 一个自包含 `.html`，存到 `./lessons/000N-<slug>.html`。用户会回头复习，所以必须**精美、可读、可打印、可离线打开**。

## 小白友好的硬约束

1. **图多字少**：核心机制用 SVG 图示 / 类比图表达。每屏只讲一件事，正文克制。
2. **先类比，后精确**：先生活类比让人"啊哈"，再给一句精确表述（精确句可折叠或置底）。
3. **禁行话**：除非该词已进 `references/glossary.md`，且本页首次出现时就地用大白话解释。
4. **一个可带走的小收获**：结尾用户应能复述一个要点。
5. **紧扣 MISSION**：说明"懂这个对你那个目标有啥用"。
6. **一句提醒**：页尾提示"有不懂的随时问，我可以接着讲"。

## 版面（Tufte 风）

- 单栏、大留白、字号可读（正文 17-18px，行高 1.7）。
- 配色克制：1 个主色 + 中性灰底；不用渐变滥用、不用刺眼高亮。
- 图示内联 SVG（不依赖外部图片/CDN），保证离线可开。
- 每课链 `../assets/base.css`，看起来像同一门课。
- 通过 HTML 锚点互链其它课与 reference 文档。

## 可选增强

- **回忆练习**：小卡片"合上页，试着说出 X 是什么"，利用合意困难促长期留存。
- **一图流复习卡**：把本课压缩成"一张图带走"的总结块，适合小白复习。
- **主源推荐**：链一个高质量、高信任的外部资源（视频/文章）供深读，提升可信度。

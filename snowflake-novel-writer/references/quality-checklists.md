# 质量自检清单

## 通用检查

### 章节结构
- [ ] 开头 3 句是否有钩子？
- [ ] 章中是否有至少一个冲突/转折？
- [ ] 章末是否有悬念或情感爆发推动翻页？

### 开头
- [ ] 是否在 500 字内建立人物和冲突？
- [ ] 是否避免了"醒来""天气预报式"开头？
- [ ] 是否有具体感官细节？

### 推进
- [ ] 每段是否有"谁想做什么→为什么此刻做→遇到什么阻力"？
- [ ] 是否有信息递进而非重复？

### 信息传达
- [ ] 是否用场景展示而非叙述告知？
- [ ] 对话是否同时推进情节和揭示性格？

### 场景
- [ ] 是否有至少一个可视化细节？
- [ ] 意象回环是否自然？

## 长篇专项

- [ ] 黄金前三章是否建立了核心矛盾？
- [ ] 节奏是否有张有弛（不能一直高潮也不能一直铺垫）？
- [ ] 人物是否保持一致性（没有突然性格大变除非有弧线支撑）？

## 短篇专项

- [ ] 虐爽节奏是否到位？
- [ ] 对白密度是否合理？
- [ ] 打脸场景主角是否保持冷静？
- [ ] 证据链是否完整闭环？

## 去AI味专项

- [ ] 是否存在禁用词？（见 banned-words.md）
- [ ] 是否有排比三连？
- [ ] 是否有升华式收束？
- [ ] 是否有总结式结尾句？
- [ ] 心理描写是否由动作/细节替代？
- [ ] 对话是否有人物声差？

# 开头设计

## 黄金章节原则

前3章决定读者是否继续。每章必须完成一个承诺+一个悬念。

## 3个开头锚点

选择一种开头方式：

1. **冲突锚** — 以冲突/危机/异常事件开始
2. **人物锚** — 以强烈的人物特质/动作开始
3. **氛围锚** — 以独特的场景/意象开始

## 8种题材开头模板

| 题材 | 开头模式 | 避免方式 |
|------|---------|---------|
| 都市脑洞 | 重生/觉醒的瞬间 | 不要以日常生活流水账开篇 |
| 总裁 | 身份反差场景 | 不要平铺介绍家族 |
| 古代宅斗 | 入府第一天/某个仪式 | 不要大段世界观介绍 |
| 仙侠 | 被欺负/被轻视的场景 | 不要以修炼体系介绍开篇 |
| 校园 | 课间/考试/活动中的冲突 | 不要以校园景色描写开篇 |
| 现实情感 | 关系转折点 | 不要以内心独白开篇 |
| 喜剧 | 荒诞场景直接进入 | 不要铺垫正常再转荒诞 |
| 年代/复合 | 时代标记物+人物困境 | 不要以历史背景介绍开篇 |

## 开头决策树

```
你的故事核心是什么？
├─ 冲突强 → 用冲突锚开头
│  └─ 冲突在情节中间 → 用倒叙/中段切入
├─ 人物强 → 用人物锚开头
│  └─ 人物有反差 → 直接展示反差行为
└─ 世界强 → 用氛围锚开头
   └─ 世界有秘密 → 用异常细节暗示秘密
```

## 开头黄金规则

1. 前500字必须出现人物+冲突
2. 不要以"醒来"开头
3. 不要以天气/风景描写开头（除非它是关键线索）
4. 不要大段介绍世界观 — 角色发现世界观比作者介绍世界观好
5. 第一句决定全文气质 — 选词、句式、节奏都在第一句定型

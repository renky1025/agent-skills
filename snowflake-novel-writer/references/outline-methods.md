# 大纲编排方法

## 五步大纲法

1. **定高潮** — 这个故事最震撼的那一刻是什么？
2. **定单元情节** — 从高潮反推需要哪些铺垫情节
3. **组织线索+前埋信息** — 伏笔和信息揭露的时间线
4. **定开局** — 用黄金前三章原则设计开局
5. **定结局** — 高潮之后的余波和收束

## 八节点故事结构

适用于三幕式的细化版：

| 节点 | 功能 | 建议字数占比 |
|------|------|-------------|
| 开局 | 建立人物和冲突 | 10% |
| 发展 | 推进矛盾 | 20% |
| 转折1 | 打破平衡 | 10% |
| 转折2 | 深化冲突 | 15% |
| 高潮 | 核心对立爆发 | 15% |
| 冲突收束 | 解决主要矛盾 | 10% |
| 转折3 | 额外转折/余波 | 10% |
| 结局 | 收束与余味 | 10% |

## 升级感设计三步法

适用于成长升级型故事：

1. **列起点** — 主角目前状态（能力、地位、认知）
2. **列终点** — 主角最终状态
3. **反推缺口** — 从终点往回看，每个能力/认知缺口对应一个情节单元

## 矛盾设计四级法

1. **表层矛盾** — 人物之间的直接冲突
2. **深层矛盾** — 价值观/世界观的碰撞
3. **底层矛盾** — 世界观设定层面的结构性矛盾
4. **递进规则** — 每一级矛盾解决后暴露下一级

## 双线结构

- **明线（A线）**：升级/成就/外部目标推进 — 给读者的明爽
- **暗线（B线）**：人物/关系/内心变化 — 给读者的暗爽
- 两者交织推进，避免纯A线推进（干）或纯B线推进（淡）

## 黄金前三章原则

- 第一章：建立核心矛盾+钩子
- 第二章：深化人物+第一个转折
- 第三章：确认方向+让读者无法离开

## 情节质量控制

- **相似性检查**：两个情节是否太像？删掉或合并一个
- **匹配检查**：这个情节是否服务于主线或主人物？如果不服务，删掉
- **时空比例**：叙事时间与故事时间的比例是否合理
